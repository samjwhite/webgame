# Літо в селі

Піксельна броділка з квестами: літо 2003-го, село на Полтавщині.

## Як грати

- Телефон: тягни пальцем по екрану, щоб ходити. Кнопка **A** — говорити або діяти.
- Комп'ютер: стрілки або WASD — ходити, пробіл / Enter / E — діяти.
- iPhone: відкрий у Safari → «Поділитися» → «На екран “Додому”».

## Локальний запуск

```
python3 -m http.server 8000
```

Потім відкрий http://localhost:8000.

## Публікація

GitHub Actions публікує гру з гілки `main`.
Перший раз увімкни Pages: Settings → Pages → Source: **GitHub Actions**.
