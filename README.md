# Літо в селі

Піксельна броділка з квестами: літо 2003-го, село на Полтавщині.

## Як грати

Мову (українська, англійська, італійська) обирають прапорцем на титульному екрані. Усі тексти гри лежать у `js/text/uk.js`, `en.js`, `it.js` з однаковими ключами.

- Телефон: тягни пальцем по екрану, щоб ходити. Кнопка **A** — говорити або діяти.
- Комп'ютер: стрілки або WASD — ходити, пробіл / Enter / E — діяти.
- iPhone: відкрий у Safari → «Поділитися» → «На екран “Додому”».

Гра зберігається автоматично в браузері. На титульному екрані — «Продовжити» або «Нова гра».

## Арт

Уся графіка — PNG у папці `art/`. Її генерують скрипти з `tools/art/`:

```
python3 tools/art/build.py
```

Карта села, портрети, сцени і персонажі зроблені з картинок у `tools/art/reference/`. Додай `?debug` до адреси, щоб побачити невидимі стіни. Будь-який PNG можна замінити намальованим вручну файлом того самого розміру.

### Генерація арту (/art)

`tools/art/codex_art.py` малює картинки через Codex CLI з входом у ChatGPT Plus, без API-ключа. Результати — лише кандидати в `tools/art/reference/generated/`; у референси вони потрапляють через `tools/art/promote.py ... --approve` після схвалення. Деталі: `.claude/skills/art/SKILL.md` і `docs/CODEX_SETUP.md`.

## Тести

```
npm test
```

Нічого встановлювати не треба, досить Node 22. Подробиці в `docs/TESTING.md`. Панель розробника: додай `?dev` до адреси гри.

## Локальний запуск

```
python3 -m http.server 8000
```

Потім відкрий http://localhost:8000.
