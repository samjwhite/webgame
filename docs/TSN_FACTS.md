# TSN news in the game: what is fact and what is a joke

The evening news (`tsn` in `js/text/*.js`) uses real events up to summer 2003, retold as comedy. Keep to these rules when adding bulletins:

- Real events only, and only ones that had already happened by the game's date (summer 2003).
- Never invent quotes for real people. The joke comes from the newsreader and the village reacting to the event.
- Nothing later: for example the Tuzla conflict and the book "Україна — не Росія" are autumn 2003 (September for the book), so they wait until the game gets there.
